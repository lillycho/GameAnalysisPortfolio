# 게임 분석 포트폴리오

사용자가 제공한 와이어프레임과 PDF 8개를 기반으로 GitHub Pages에 업로드 가능한 정적 웹사이트를 만든다. 3열 썸네일, 한국어 제목, 영문 이름, 날짜를 유지한다. 모바일은 1열, 태블릿은 2열로 전환한다.

구현 선택: HTML/CSS/JavaScript와 미리 렌더링한 WebP 페이지를 사용한다. 브라우저 내장 PDF 임베드는 모바일 동작이 일관되지 않고, PDF.js는 추가 런타임 의존성이 필요하다. 이미지 방식은 원본의 시각적 구성을 보존하며 지연 로딩이 가능하다. 텍스트 선택·검색은 원본 PDF 링크로 제공한다. 이 선택은 구현자의 판단이다.

상세 화면은 해시 URL로 직접 공유·새로고침이 가능하다. 세로 스크롤, 페이지 이동, 확대, 원본 PDF, 목록 복귀, 다음 프로젝트를 제공한다. 모션 감소 설정과 키보드 포커스를 지원한다. 날짜는 표지에 표기된 날짜를 사용한다. 연락처와 경력 등 제공되지 않은 정보는 만들지 않는다.

기존 PDF는 변경하지 않는다. 외부 서비스와 빌드 없이 작동하게 하고 GitHub 배포 방법을 안내한다. 실제 계정 배포는 이번 요청의 '바로 올릴 수 있는 형태' 범위에 포함하지 않는다.
